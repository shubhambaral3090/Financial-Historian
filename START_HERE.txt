FINANCIAL HISTORIAN — BROWSER WEB APP

1. Extract All from the ZIP into a folder you can write to.
   Keep all files together; do not launch inside the ZIP.
2. Use installed Python >=3.12 and <4.
   Python 3.12, 3.13 and 3.14.6 are tested; future versions need compatible wheels.
3. Double-click launch_windows.cmd. First launch needs internet to check and
   install dependencies. It does not silently install another Python version.
4. Enter a real name and contact email in the centered browser dialog.
   The SEC requires identifying contact for automated access. No API key,
   account, subscription or payment is needed. Contact stays in this tab's
   session, not project files. Browser session-restore settings apply.
5. Search or select a company. Prices, charts, SEC statements and Excel load
   automatically. Your next normal action is Download Excel workbook.

Refresh the browser tab for new data checks. Failed providers do not hide the
other section; cached results show original timestamps and warnings.
The sidebar uses dated, manually maintained, incomplete ticker starter groups.
Direct SEC search remains available beyond those suggestions.

Keep the launcher window open; Ctrl+C stops the web server. Closing the browser
alone does not stop it. This is not an offline Windows application.
The default server accepts connections only from your own computer.

Statements show at most 20 fiscal periods. Read Sources & Coverage and original
SEC filings before using figures in a model. No forecasts or valuations are added.

If an old .venv is incompatible, the launcher explains recovery without deleting
it. Do not disable certificate verification to fix connection errors.
README.md has details. Diagnostics never contain your SEC contact.
