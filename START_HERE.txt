FINANCIAL HISTORIAN — WINDOWS 11

1. Extract the ZIP into a folder (do not launch from inside the ZIP).
2. Use your installed Python 3.11 or newer; 3.12 and 3.14.6 passed app tests.
   If Python is missing, install it from https://www.python.org/downloads/windows/
   Select "Add Python to PATH" or install the Python launcher.
3. Double-click launch_windows.cmd. First-time installation needs internet.
4. In the browser, enter your name and contact email for SEC access.
   The app remembers these locally. No account, API key or subscription is needed.
5. Search for a company, click its result, prepare the workbook, then download it.

Keep the launcher's window open while using the app. Ctrl+C stops it.
Closing the browser does not stop the local server; close the launcher to stop it.

The browser presents the latest 20 fiscal periods for supported S&P 500 and
Nasdaq-100 companies. It does not permanently archive the full universe.
This cannot guarantee every statement line or complete lifetime history.
Older paper reports, non-SEC archives and unsupported formats need manual review.
Always read Sources & Coverage in the workbook before using figures in a model.

On first launch, enter a real SEC name and contact email in the centered dialog.
This is required by SEC automated-access regulations and remains active for the
current browser session by default. If available, the sidebar can refresh the
supported S&P 500/Nasdaq-100 company suggestions and market data.

If there is a problem, download the diagnostic log in the app's sidebar.
More detail is in README.md. Your local settings and logs are not in this ZIP.
